# Integration verification

Scope/acceptance for `feature/flow-verification` (depends on results-dashboard / PR #12): exercise the connected native screen components, preserve async storage correctness, verify platform bundles, document exact remaining live blockers and setup.

`src/fullFlow.test.tsx` mounts the actual channel, connection, photo, preview, budget, review and dashboard components with controlled storage/provider boundaries. It presses through recommendation, sample account selection, photo upload, copy generation, accuracy confirmation, phone destination, approval, simulated review, activation, pause, resume and confirmed stop. It asserts no real provider calls and covers gallery cancellation. Existing component tests cover the business opt-out, save retries and duplicate taps. These are component tests, not device end-to-end tests.

Hardening from verification: await native file-copy completion before saving its URI; reject oversized uploads before reading bytes when picker metadata is available; correct API example to include `/api`; require HTTPS for non-local backend session transport; handle revoked provider tokens; bound profile input; chunk Unicode sessions and demo profiles safely with backward-compatible reads; avoid stale blob URL leaks; bound session restore so a network stall cannot show a permanent startup spinner.

Local checks: 42 mobile/domain/component tests and 8 backend tests; TypeScript for app and server; ESLint. Android, iOS and web JavaScript export succeeded with `--no-bytecode`. An obsolete Metro cache could not deserialize once; Metro automatically rebuilt it and export completed. CI includes all-platform bundle export on this feature and lint/type/tests on preceding features. Server tests also check owner-scoped draft lookup, foreign photo rejection and stale revision rejection.

Not tested: physical Android/iOS devices or emulators (adb/Xcode unavailable), native compilation, camera hardware, a signed development build, interactive browser visual QA, live Supabase migrations/storage/Google OAuth, provider OAuth/app review, AI requests or paid campaigns. No `.env` or `.env.server` exists in this workspace. npm installation reported 13 moderate transitive dependency advisories; no force upgrade was used, because SDK compatibility must be reviewed. This is not a security certification or production-ready paid advertising service.
